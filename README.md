# Kexin (Sabrina) Geng — Personal Website

Static academic homepage served by GitHub Pages at https://sabrinagng.github.io/

- `index.html` — page content
- `styles.css`, `script.js` — layout and interactions
- `pic/profile.jpg` — add a profile photo here (a placeholder is shown until then)
- `pic/logos/` — optional institution logos (`Rice.png`, `UNC.png`, `Neusoft.png`)

Design adapted from [Honghui Chen's homepage](https://choraschan.github.io/), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
